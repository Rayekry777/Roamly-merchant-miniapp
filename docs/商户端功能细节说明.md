# Roamly 商户端功能细节说明

> 更新时间：2026-09-13  
> 适用范围：商户认证、入驻、门店经营、团购券、员工、核销、收银、结算、售后和平台客服

## 商户角色

```text
VISITOR   游客
TENANT    租户
MANAGER   店长
VERIFIER  核销员
```

商户 Token 登录类型为 `MERCHANT`。页面按角色隐藏入口，但后端仍校验当前账号、门店和权限。商户不能访问消费者工单、平台审核或管理员接口。

## 入驻和资料

- 游客可编辑入驻草稿、地图位置、七日营业时间、营业执照和最多九张经营图。
- 提交审核要求资料完整，提交带幂等键；冲突时保留输入并回查服务端版本。
- 审核通过后门店激活；门店停用和账号停用来源不能被客户端覆盖。
- 头像和经营媒体使用私有鉴权下载，临时文件绑定后才能长期保留。

## 团购券经营

支持 `PACKAGE` 套餐券、`CASH` 代金券、`DISCOUNT` 折扣券和 `MULTI_USE` 次卡。

- 四步编辑覆盖基础信息、价格库存、有效期规则和媒体提交。
- 审核状态与销售状态分开显示，提交、下架和删除使用幂等键。
- 封面一张、详情图最多九张；草稿可恢复，复制创建独立商品。
- 商品价格、补贴、库存和退款规则以服务端快照为准。

## 员工、核销和实时刷新

- 租户为已注册游客签发一次性 60 秒六位邀请凭证，指定店长或核销员。
- 核销支持扫码和手输券码；预览不改状态，确认核销必须带预览令牌和幂等键。
- 租户和店长可撤销尚未结算的误核销，核销员没有撤销权限。
- WebSocket 只刷新核销、订单和经营资源，断线后回查 REST，不改变券或订单状态。

## 收银、服务费和结算

- 今日收银固定路径为“团购数据 → 核销明细 → 收入明细”，不增加外卖入口。
- 财务摘要、核销收入、服务费、退款冲回和结算金额只使用服务端返回值。
- 商户端不提供服务费修改、结算重试、提现或退款审批按钮。
- 结算列表和详情只读展示批次、明细、平台服务费、商户净额和调整项。
- 详细公式和退款冲回见[退款客服与资金结算业务细节](../../Roamly/docs/project-details/退款客服与资金结算业务细节.md)。

## 售后和平台客服

- 商户可以按本店订单或券查询退款候选、发起退款和查看审核/执行时间线。
- 商户不能审批、拒绝、重试或直接执行退款。
- 商户可以创建本账号的退款、核销或结算客服工单，并使用游标消息、图片附件和未读。
- 工单权限真源为 `applicant_type=MERCHANT + applicant_id=当前商户账号`，不能只按 `shop_id` 查询。
- 商户看不到消费者工单和内部备注。

## 接口和验证

- 仅调用 `/v1/merchant/**`，认证为 `Authorization: Bearer <token>`。
- API 层统一处理 401、403、404、409、429、503；页面不直接解析响应包装。
- 业务 ID 为字符串，金额为分，日期按 Asia/Shanghai 展示。

```text
npm run verify
npm run build:npm
```

验证登录、角色、商品、员工、扫码、核销、撤销、收银、结算、售后、客服和断线降级。
