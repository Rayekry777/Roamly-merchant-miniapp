# Roamly Merchant Miniapp

Roamly 商户经营与核销微信小程序，用于商户入驻、店铺资料、团购券、订单、员工、扫码/手输核销、经营数据和结算查询。

当前仅完成设计冻结，功能状态为“未实现”。本目录已初始化为独立 Git 仓库，尚未生成小程序配置、依赖或源码。

目标技术栈为原生微信小程序、TypeScript、TDesign MiniProgram 和微信开发者工具。实现范围与验收要求见 [商户小程序契约](MERCHANT_MINIAPP_DEVELOPMENT.md)，实施顺序见 [四端交付路线图](../Roamly/docs/roadmap/FOUR_END_DELIVERY_ROADMAP.md)。

商户端视觉沿用现有 Roamly 消费者小程序的珊瑚红、柔紫和紫灰中性色体系；竞品页面只参考经营流程，不作为视觉样稿。
